# Dynamic Programming — Complete Lecture & Study Guide

Dynamic Programming is one of the most important topics in Data Structures and Algorithms (DSA). It is also one of those topics that initially feels confusing because you need to understand not just *how to write the code*, but also *how to think about solving a problem*.

We'll approach this like a university lecture: starting with the fundamentals, understanding the logic behind DP, and then gradually moving into the three major problems:

1. 0/1 Knapsack Problem
2. Longest Common Subsequence (LCS)
3. Coin Change Problem
   - Minimum Number of Coins
   - Number of Ways to Make an Amount

The objective is to understand the reasoning behind each algorithm, derive the recurrence relations, construct DP tables, and eventually become capable of solving similar problems independently.
