# 9. Important mistakes to avoid in the examination

After reviewing the materials, these are the things I'd be particularly careful about.

| Topic | Common mistake | Correct approach |
| --- | --- | --- |
| Frequency Distribution | Total frequency does not match observations. | Always verify $\sum f=n$. |
| Class Width | Rounding down. | Round up when choosing a convenient class width. |
| Relative Frequency | Forgetting to convert to percentage. | Multiply by 100 when percentage is required. |
| Histogram | Leaving gaps between bars. | Adjacent bars for continuous classes. |
| Pie Chart | Forgetting the angle calculation. | Total angle must equal 360°. |
| Mean | Using an ordinary mean when weights differ. | Use Weighted Mean. |
| Median | Not arranging data first. | Sort before finding the median. |
| Grouped Median | Using the wrong median class. | Use cumulative frequency and $N/2$. |
| Grouped Mode | Using the wrong adjacent-class frequencies. | Calculate both $\Delta_1$ and $\Delta_2$. |
| Variance | Using $n$ for sample variance. | Use $n-1$. |
| Standard Deviation | Forgetting the square root. | SD is the square root of variance. |
| CV | Comparing SDs directly when comparing relative consistency. | Calculate both CVs. |
| Skewness | Confusing the direction of the tail. | Right tail = positive; left tail = negative. |
| Kurtosis | Confusing leptokurtic and platykurtic. | Greater than 3 = leptokurtic; less than 3 = platykurtic. |
| Correlation | Thinking positive correlation means strong correlation. | Direction and strength are separate. |
| Hypothesis Testing | Using the wrong t critical value. | Check whether the test is one-tailed or two-tailed. |
