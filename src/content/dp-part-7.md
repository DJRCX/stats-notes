Understanding the theory is only the first step. You should now test whether you can independently derive the DP states and recurrence relations.

## Additional coding exercises

Try these without looking at the solutions.

**Beginner level**

1. Fibonacci using memoization.
2. Fibonacci using tabulation.
3. Minimum number of coins for `[1, 2, 5]` and target `11`.
4. Count the number of ways to make amount `5` using `[1, 2, 5]`.

**Intermediate level**

5. Solve 0/1 Knapsack with 5 items and capacity 10.
6. Find the LCS of `AGGTAB` and `GXTXAYB`.
7. Implement LCS and print the actual subsequence, not just its length.
8. Modify minimum coin change to print the actual coins selected.

**Advanced level**

9. Implement 0/1 Knapsack using a one-dimensional DP array.
10. Solve the coin change problem where each coin can only be used once.
11. Count ordered ways (permutations) to make an amount.
12. Solve the Longest Increasing Subsequence problem.
